# GitHub Pages 배포

`frontend` 폴더 안의 파일과 폴더를 저장소 루트에 올립니다.

```text
index.html
app.js
config.js
styles.css
report.html
report.js
report.css
assets/
sample_reports/
```

GitHub 저장소에서:

```text
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save
```

현재 `config.js`에는 테스트용 Google Form과 공개 처리결과 Spreadsheet ID가 입력되어 있습니다.
